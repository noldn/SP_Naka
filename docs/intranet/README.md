# Intranet-Übernahme

Dieser Ordner enthält Inhalte, die fachlich geprüft und für eine spätere Übernahme
in das Intranet aufbereitet werden.

## Empfohlener Freigabeprozess

1. Inhalt aus Notizen und Entscheidungen zusammenfassen.
2. Fakten, Quellen und Aktualität fachlich prüfen.
3. Vertraulichkeit und Veröffentlichungsrechte prüfen.
4. Personenbezogene Angaben entfernen oder freigeben lassen.
5. Verantwortliche Person und Standdatum ergänzen.
6. Inhalt ins Intranet übertragen und den Zielort hier dokumentieren.

GitHub ist nicht automatisch der geeignete Speicher für interne Informationen.
Die zulässige Ablage hängt von der Sichtbarkeit des Repositorys und den Regeln des
Unternehmens ab.
