# Entscheidungsprotokoll

Grundsatzentscheidungen werden als kurze Architecture Decision Records (ADR)
gespeichert. Dateinamen folgen dem Muster `NNNN-kurzer-titel.md`.

Eine bestehende Entscheidung wird nicht rückwirkend umgeschrieben. Eine neue
Entscheidung kann sie ersetzen und verweist dann auf das ältere Dokument.
