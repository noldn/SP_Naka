# Arbeitsnotizen

Dieser Ordner enthält nicht vertrauliche, längerfristig nützliche Arbeitsnotizen.
Neue Dateien verwenden möglichst das Muster `JJJJ-MM-TT-kurzer-titel.md` und die
Vorlage `TEMPLATE.md`.

Nicht hier ablegen:

- Kennwörter, Tokens oder Zugangsdaten
- echte Rohdaten oder Datenauszüge
- personenbezogene Informationen
- ungeprüfte interne Inhalte, die nicht auf GitHub gespeichert werden dürfen
