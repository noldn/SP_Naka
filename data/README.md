# Lokale Daten

Die eigentlichen Projektdaten werden unter `data/local/` gespeichert und durch
`.gitignore` von der Git-Versionierung ausgeschlossen.

In GitHub gehören nur:

- diese Dokumentation,
- kleine, künstlich erzeugte Beispieldaten ohne vertrauliche Informationen,
- optional ein dokumentiertes Datenschema.

Keine echten lokalen oder personenbezogenen Daten committen. Falls später
Beispieldaten benötigt werden, sollten sie in einem separaten Ordner
`data/examples/` liegen und vor dem Commit geprüft werden.
